# English Learning — voice pool

**Status:** PLACEHOLDER. Voice IDs to be assigned during channel provisioning (build step 13).

## Rotation rule (enforced by `voiceover-elevenlabs` skill)

- Pool size: 3-5 ElevenLabs voice IDs
- Never same voice twice in a row on this channel
- Voice IDs in this pool MUST NOT appear in any other channel's voice-pool.md (cross-channel voice bleed prevention)

## Voice selection criteria (per `brand.md` tonal rules)

- Clear, articulate pronunciation suitable for intermediate ESL learners (B1-B2)
- Slower-than-native cadence capability (target ~140 wpm playback)
- Warm, friendly register — never childish, never robotic-monotone
- Mix of accents acceptable as long as each is consistent within an episode (US, UK, AU — exposes learners to variety across episodes)
- Test against sample script before adding to pool; reject any voice with mispronounced English-learning-relevant words
